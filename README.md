## Run

Use Node.js 22.18 or later. No dependencies need to be installed.

```sh
npm start
```

By default, the program writes `/output/entry.png`. Set `MAKEFUN_OUTPUT_DIR` to choose another output directory. It validates the image dimensions and size, then confirms that the output size and SHA-256 match the source.

The output uses the competition's required `entry.png` filename and retains the original JPEG bytes without re-encoding.
